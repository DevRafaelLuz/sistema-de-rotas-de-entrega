# 📦 Sistema de Rotas de Entrega

Este repositório contém a atividade desenvolvida para a disciplina da Cruzeiro do Sul Virtual, com foco na criação de um **sistema de rotas de entrega**.  
O objetivo é aplicar conceitos de programação, organização de código e boas práticas de desenvolvimento em um projeto prático.

## 🚀 Objetivos da Atividade
- Implementar um sistema capaz de gerenciar rotas de entrega.
- Aplicar lógica de programação para otimizar trajetos.
- Utilizar versionamento de código com Git e GitHub.
- Documentar o projeto de forma clara e organizada.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** C
- **Ferramentas:** Git, GitHub
